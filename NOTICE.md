# Third-party services and generated media

The MIT License covers the source code and original example configuration in this
repository. It does not relicense VOICEVOX, its voice libraries, FFmpeg, user-provided
assets, or media generated with them.

VOICEVOX is not bundled. Before publishing generated audio, check both the current
[VOICEVOX software terms](https://voicevox.hiroshiba.jp/term/) and the terms for every
voice library you select. Include the required credit in the video or its description.
The pipeline writes `build/credits.txt` from `project.yaml` to make this easier.
